🪙 Local Storage via Isar • Material 3

Privacy-Focused Personal Finance Without Leaks.

An offline-first expense tracker and asset management app built with Flutter and Isar NoSQL database. Features smart spending insights, multi-account aggregation, and zero cloud dependencies.

↓ Download Latest Release APK Add to Obtainium View on GitHub
🔒
100% Local-First with Isar
Lightning-fast embedded NoSQL database running entirely on-device with zero cloud telemetry and zero sync delays.
🎨
Material 3 Expressive Design
Tonal elevation, dynamic color harmonies, custom typography, and smooth micro-interactions tuned for 120 FPS frame pacing.
📊
Smart Spending Insights
Visual analytics breaking down monthly trends, category budgets, and recurring expense forecasting without external processing.
💳
Multi-Account Management
Consolidate bank accounts, credit cards, cash reserves, and digital wallets into a single cohesive net worth dashboard.
⚡
Riverpod Reactive State
Architected with compile-safe Riverpod state management and GoRouter declarative navigation for glitch-free responsiveness.
🛡️
Zero Data Collection
No tracking analytics, no user profiling, and no third-party advertisements. Your financial logs belong solely to you.
