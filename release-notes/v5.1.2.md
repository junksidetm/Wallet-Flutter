### ✨ What's New in v5.1.2

**🎨 Material 3 Expressive**
- 🎠 **Accounts carousel**: the account cards now sit in a Material 3 `CarouselView`, and the page dots follow the card in view.
- 🧩 **New building blocks** (added, not wired into every screen yet): animated gradient text, morphing FAB, expressive segmented control, fluid mesh background, glass card, tactile keypad and an M3 search anchor.
- 🌐 **Redesigned landing page** on GitHub Pages, with a vector logo.

**⚡ Faster & Lighter**
- 📦 **About 35 MB of duplicate icon fonts removed** from the app bundle. Icons still come from the same icon packages, so nothing looks different.
- 🛠️ The Isar database inspector now runs only in debug builds.

**🛡️ More Robust**
- 🔁 **Recurring transactions** are checked once per launch. Before, a theme or route change could start a second check while the first was still running.
- 🔄 **In-app updater** now checks `github.com/junksidetm/Wallet-Flutter` and understands tags like `v5.1.2`.
- 🧹 Removed placeholder demo cards ("Main Checking $4,250") from the Home screen.
- 👆 Account cards in the carousel respond to taps again (the edit button works).

**♿ Accessibility**
- 🗣️ 25 icon-only buttons now have labels, which screen readers announce and long-press shows as tooltips.

**🔗 Project**
- 🏠 All in-app links now point to [github.com/junksidetm/Wallet-Flutter](https://github.com/junksidetm/Wallet-Flutter).
- 🏷️ Releases are now tagged with the real app version (`v5.1.2`) instead of `v1.0.0-b<build>`.
